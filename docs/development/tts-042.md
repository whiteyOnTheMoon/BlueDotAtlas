# M03 / 042 — Actual narration WAV: local and opt-in

**Status:** [Issue #66](https://github.com/whiteyOnTheMoon/BlueDotAtlas/issues/66); candidate 042 feature PR under technical review, not a completed or published film.

## Why a real voice now, without a paid subscription

The 037 script contains **seven English narration fragments** for *Hurricanes: Powered by the Ocean*. The 042 test speaks those exact seven fragments now so their natural duration, spoken clarity, pauses and pronunciation can be compared with later editorial timing in 044. **No fake sine tones or placeholder silence** may be accepted as actual speech.

For this bounded proof, use **Kokoro-82M v1.0** via **kokoro-onnx 0.6.1**, a local open neural speech model:

- [Kokoro model and voicepacks](https://huggingface.co/hexgrad/Kokoro-82M): Apache License 2.0 upstream, including published model/voicepack; original author states commercial deployments are possible subject to license and per-output review.
- [kokoro-onnx runtime](https://github.com/thewh1teagle/kokoro-onnx): MIT, Python package 0.6.1, no vendor API account, remote synthesis or voice cloning. **One trial British English preset voice `bm_george`** at speed `1.0`; neutral documentary character to be decided only by a real listening review.
- Official release model URLs are fixed to `model-files-v1.0`, bytes streamed **only** to the disposable GitHub runner and verified against exact SHA-256 values recorded publicly in [unmodified ONNX mirror](https://huggingface.co/ExNihilus/kokoro-onnx):
  - `kokoro-v1.0.onnx` SHA256 `7d5df8ecf7d4b1878015a32686053fd0eebe2bc377234608764cc0ef3636a6c5` (capped at 350MB)
  - `voices-v1.0.bin` SHA256 `bca610b8308e8d99f32e6fe4197e7ec01679264efed0cac9140fe9c29f1fbf7d` (capped at 35MB)
- Fixed, limited speech output: **PCM16 WAV, 48kHz, stereo**, 120ms head lead-in, 280ms between script fragments, 350ms tail; no artificial final-fade or wholesale time stretching, since that could truncate phonemes and destroy phonetic quality. Exact segment and total durations are emitted in timing metadata. Outputs are **not automatically aligned** to 037 shot frame windows. 043–044 later own soundtrack mixing/editing and true word timing.

## Source, quality and security controls

`scripts/tts-042-plan.mjs` builds an independent, locked JSON plan from the committed 037 script. It requires `planning_only=true`, `render_authorized=false`, `publish_authorized=false`, exactly seven unmodified source narration fragments, fixed provider `kokoro-onnx-local`, language `en-gb`, voice `bm_george`, rate/pause profile, and a SHA of the script.

`scripts/generate-tts-042.py` runs only with `CI=true` and `BDA_TTS_042_PRIVATE_TEST=TRUE`, downloads two exact sources with size/HTTPS/host/SHA checks and synthesizes original spoken sentences with preset voice; it never sends script or voice data to a remote inference provider. Exact download URL host redirects are allowlisted; model assets, temp plan and output all stay under **`.tmp-tts-042/`**, ignored from Git. Output is `.tmp-tts-042/audio/pilot-narration.wav` plus timing/meta JSON; not the permanent `audio/` tree or a public song/video artifact.

`scripts/check-tts-042.py` independently checks actual WAV stream properties (48kHz, stereo, PCM16), per-shot segment counts, range of durations, PCM peak/non-silence, safe initial and final silence, absence of multi-second dead air, file- and source-SHA matching, and explicit manual-review requirement. `scripts/tts-042-plan.test.mjs` includes negative tests for unauthorized film/publish flags and malformed voice text. **Automated QA cannot confirm correct pronunciation, breath timing, expression, syllable completeness or rights for a *final* public recording**. These require listening and explicit owner approval.

[Dedicated GitHub Actions 042 workflow](../../.github/workflows/pilot-tts-042-check.yml) uses a throwaway GitHub Ubuntu runner and pinned Python libraries; it uploads **only synthetic/generated WAV + timing report** as a **5-day review artifact** (not model weights or credentials) and then deletes all transient assets. As with older task 039, **model weights are never checked into the intentionally public repository**. No additional VPS workload, web app, remote TTS service, paid plan or Docker container is enabled in this task.

### Reproduce only in a disposable isolated CI runner

    CI=true BDA_TTS_042_PRIVATE_TEST=TRUE node scripts/tts-042-plan.mjs
    python scripts/generate-tts-042.py
    python scripts/check-tts-042.py .tmp-tts-042/audio/pilot-narration.wav .tmp-tts-042/audio/pilot-narration-qa.json

Requires a separately prepared pinned Python 3.12 environment with `kokoro-onnx==0.6.1`, `numpy==2.2.6`, `scipy==1.16.3` and `espeak-ng`. **Do not** run this on the shared VPS while production services operate without a new infrastructure approval. The GitHub CI workflow is the supported reproducible route.
